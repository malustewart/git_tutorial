# Tutorial de git

## Requisitos

El tutorial fue desarrollado en y testeado en Windows 10 con wsl (Ubuntu). Alternativamente, debería poder seguirse en una distribución de Linux basada en debian.

Antes de comenzar, se debe instalar:
 - git
 - Visual Studio Code (abreviado como VS Code, o vscode)
 - Extensión de vscode: mhutchie.git-graph

### Instrucciones de instalación
 - git: https://learn.microsoft.com/en-us/windows/wsl/tutorials/wsl-git#installing-git
 - vscode: https://code.visualstudio.com/docs/setup/windows#_install-vs-code-on-windows
 - Extensión de vscode mhutchie.git-graph: https://marketplace.visualstudio.com/items?itemName=mhutchie.git-graph
